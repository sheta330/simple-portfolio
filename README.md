# Khaled Sheta - Simple Portfolio

A clean, modern portfolio website built with HTML, CSS, and JavaScript featuring smooth animations and responsive design.

## Features

- ✨ Smooth scroll animations
- 🎨 Modern gradient design
- 📱 Fully responsive
- 🚀 Fast loading
- 🎯 Clean navigation
- 💫 Interactive hover effects
- 🌊 Parallax floating shapes
- ⌨️ Typing effect
- 📧 Contact form

## How to Use

Simply open `index.html` in your web browser. No build process or dependencies required!

### Quick Start

1. Open the folder in your file explorer
2. Double-click on `index.html`
3. The portfolio will open in your default browser

## Customization

### Update Personal Information

Edit `index.html` to change:
- Name and title in the hero section
- About me description
- Skills and projects
- Contact information

### Change Colors

Edit `styles.css` and modify the CSS variables in the `:root` section:

```css
:root {
    --primary: #667eea;
    --secondary: #764ba2;
    --dark: #333;
    --light: #f8f9fa;
    --white: #ffffff;
    --gradient: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}
```

### Add/Remove Projects

Edit the projects section in `index.html` to add or remove project cards.
